2Erkennung

Handerkennung (MediaPipe). Zum Testen ohne Bauteil.

Das Handmodell (7,8 MB, von Google) fehlt noch.

Das Programm lernt dein Objekt aus etwa 5 Fotos: Objekt in die Kamera halten, einmal anklicken, fertig. Danach findet es das Objekt bei anderem Abstand und leichter Drehung wieder.

Dafür fehlen die Bild-Modelle (ca. 133 MB, einmalig, von Hugging Face).

So lernst du ein Teil ein
  1. Teil in der gewünschten Nullstellung vor die Kamera legen.
  2. Kamera starten, Aus Livebild einlernen drücken (das Bild friert ein).
  3. Rechteck eng um das Teil ziehen, Namen eingeben, speichern.
  4. Das neue Referenzbild ist sofort ausgewählt.

Voraussetzungen: gleichbleibender Abstand Kamera–Teil (±10 % Größe verfälscht die Pose), ein asymmetrisches Merkmal am Teil, mindestens ~70 % sichtbar.
